# 统一线索分配与邮件通知

2026-09-27，工作树 `~/.worktrees/leadsgen/unified-lead-handoff`。

## 行为

管理员在全部线索里按负责人、来源、接手状态、逾期筛选。详情包含交接历史、退回原因、下一步与日期、独立的通知发送状态。销售只看本人负责或待本人接手的记录。

分配与通知快照在同一事务保存。邮件由 Aimail 的集成接口投递，包含摘要、接受／退回入口，以及共享线程的原邮件附件。按钮仅打开已登录员工的详情，确认使用受权限和版本保护的 POST。邮件服务接受不代表送达或已读；不确定投递不自动重发。

已有 Aimail 交接同步到同一列表，负责人及交接决定仍以 Aimail 为准，Leadsgen 接受／退回通过集成接口执行后刷新。已接手记录不会要求再次接手。旧记录不补发通知；新 Aimail offer 事件显式携带通知标志。历史交接重新分配仍通过详情中的原邮件入口，避免两套负责人。

## 已知边界

邮件正文顶部按钮兼容常规 HTML 邮件，不依赖邮件客户端执行脚本或支持悬浮定位；详情页顶部提供确认操作。原始线程总量超过 20 MiB 时通知排队报错，管理员需处理附件；不会静默去掉附件。通知状态 unknown 需核对个人发件记录，不能自动重复发送。
